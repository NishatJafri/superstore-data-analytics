# Git Workflow Practice

This project uses Git and GitHub for version control.

- `git clone`: Copies the repository to the local system.
- `git add`: Stages project changes.
- `git commit`: Saves changes with a meaningful message.
- `git push`: Uploads local commits to GitHub.
- `git pull`: Retrieves and integrates remote changes.

Three meaningful commits are planned to track the dataset, documentation, and project analysis files.
